## 方案 A：本机使用（最简单）

1. 安装 Python 3：https://www.python.org/downloads/ （安装时**勾选 Add Python to PATH**）
2. 双击 `update.bat`（Windows）或 `update.command`（macOS，若提示无法验证，右键→打开）
3. 脚本跑完后会自动打开 `index.html`
4. 保持页面打开，点顶部「开启桌面通知」
5. 电脑设置里把「睡眠」设为**从不**（屏幕可关，睡眠不能开）

**以后每天**：双击一次 `update.bat`，等 10 秒，页面就是最新数据。

> 只打开不发请求的 `index.html` 也能看，但雷达分数会停在最后一次生成的日期。

## 阶段隔离开关

页面顶部「当前阶段」两个按钮：

- **左侧寻底阶段（默认）**：MA20/MA60 的橙/深红报警静音——只显示数值，不弹窗、不响铃；保留暴跌/磨底/1H/4H 的买入提醒。
- **右侧持仓逃顶阶段**：MA20/MA60 清仓报警全面激活，破位立刻弹深红窗 + 警示音。
- **牛市主升浪（新增）**：
  - MA10 静音——跌破止盈线只灰显，**不触发减仓**（依据：2015-2026 的 13 次牛市洗盘，13 次全部假摔，平均 8.5 天重回 MA10）；
  - 跌破 MA20 仍减半，但**10 个交易日内重回 MA20** → 弹蓝色【假摔收回，建议买回减掉的仓位】；
  - 收盘跌破 MA60 但幅度 **<1.5%** → 只弹橙色【浅破 MA60，观察 10 天】；**第 11 天仍未收回，或幅度扩大到 1.5% → 自动升级深红清仓**。

选择会记在浏览器（localStorage），下次打开保持上次选择。
也可用网址强制：`index.html?phase=right` 或 `?phase=left`。

## 辅助执行工具（页面最下方）

1. **积存金网格计算器**：输入计划总预算 / 已投入 / 已持有克数 / 当前金价 / 首档价 / 档距%，四档按 1:2:3:4 自动算金额与克数。**档位不预设固定点位**，由「首档价 × 每档下移 X%」动态生成，你可随时改首档价和档距；现价跌到某档时该行高亮「已触发」。克价 = 美元点位 × 汇率 ÷ 31.1035（汇率自动取实时 USD/CNY），并与沪金 AU0 实时克价对照。
2. **动态回撤追踪（替代原移动止损）**：
   - 止盈线 = 本轮内「近 20 日最高 − 3×ATR14」的**最高值**，**只上移不下移**（本轮起点 = 最近一次收盘上穿 MA60）；
   - **只用日线收盘价**判定，盘中插针/砸盘不算；
   - **震荡过滤**：偏离 MA20 绝对值 < 3% 时暂停触发；
   - 触发只提示**减仓一半**（橙色），清仓仍死等**收盘跌破 MA60**。
3. **交易日志**：日期 / 动作 / 价格 / 仓位 / 情绪，存在本机浏览器（localStorage），可导出 JSON。

## 全系统无预设价位（重要）

页面**不再包含任何写死的价格数字**（此前的 3959 / 3850 已全部移除）：
- K 线图不画预设价位虚线；
- 顶部卡片改为「近 60 日区间位置」「偏离 MA20」；
- 磨底黄灯 = 磨底 ≥3 **且** 近 60 日区间位置 ≤20%（或跌破布林下轨），跌到 3700 照样亮、4300 横盘绝不亮；
- 灰条只显示「60日位置(收盘) X%」，纯参考，不参与任何触发。

## 提醒规则（已锁定）

> **卖出信号同样基于日线收盘价确认，严禁盘中假突破/假跌破触发操作！**

> 说明：逃顶雷达、MA20/MA60 防守线、磨底黄灯均取「最近一个完整交易日收盘」；盘中价格跳动不会改变这些判定。1H/4H 短线雷达例外，它按小时线盘中变化，只用于短线，不可当建仓依据。

| 提醒 | 条件 |
|---|---|
| 极速反弹机会出现（红） | 暴跌雷达 ≥3/4 且右侧确认（MACD 金叉 或 站上 MA5 且 MA5 拐头） |
| 进入震荡底部区（黄） | 磨底雷达 ≥3/4 **且价格处于近 60 日低位区**（动态判定，不写死点位） |
| 跌破 MA20（橙） | 收盘价 < MA20 → 建议减仓一半 |
| 跌破 MA60（分层） | 按「环境 × 位置」判定：<br>牛市+高位（距一年高 <10%）→ **不动**（灰，视为洗盘）<br>过渡期（年线刚转向）→ **清仓**（深红）<br>其余（熊市/中低位）→ **减半**（橙） |
| 终极警告（深红） | 近 10 日逃顶雷达 ≥3 分，且当前收盘 < MA20 |

页面顶部右侧「预览提醒样式」可查看红/黄弹窗效果（标注为样例）。

## 信号台账（ledger.csv）

每次运行「一键更新」，会自动把当天的判定追加到 `ledger.csv`：

| 列 | 含义 |
|---|---|
| env / zone | 环境（牛/熊/过渡）· 位置（高/中/低） |
| action60 | MA60 破位时应做的动作（守住/不动/减半/清仓） |
| score / s_space / s_mom / s_pat / s_vol | 磨底雷达总分与四项 |
| pos60 / below_lower | 60 日位置 · 是否跌破布林下轨（仅提示） |
| yellow / seq | 是否黄灯 · 第几次 |
| r20 / r40 / r60 | **回填**：信号后 20/40/60 个交易日的实际涨跌 |

**用途**：一年后拿这份表做样本外复检，不用重新推数据。

- 每天自动增量追加，不会重复
- `r20/r40/r60` 会在满 20/40/60 个交易日后自动回填
- 想补录历史：`python ledger.py --from 2026-01-01`

## 免责声明

本工具只做行情数据展示与机械规则提示，不构成投资建议，不代下单。历史回测不代表未来收益。## GLD 持仓（资金行）

页面顶部新增第三行「资金」，显示 SPDR 黄金 ETF（GLD）的实物持仓：

```
GLD 1040.8 吨 · 20日 -18.0 吨 (-1.7%)
60日 +33.8 吨 (+3.4%) · 一年 999.02–1101.33 吨 · 2026-10-26
```

- **数据源**：SPDR 官方历史档案（xlsx，每个交易日更新）
- **含义**：西方 ETF 资金的进出。持仓增 = 有资金在买实物，减 = 在赎回
- **定位**：**只展示，不参与任何判定**。不进雷达、不进黄灯、不进清仓线
- **失败时**：显示「GLD 数据未取到」，不影响页面其他部分

为什么不用 COMEX：伦敦金是 OTC 市场没有公开成交量，页面量能用的是上海期货交易所 AU0（沪金主力）的成交量，反映中国投资者热度；GLD 持仓反映的是西方资金，两者互补。
