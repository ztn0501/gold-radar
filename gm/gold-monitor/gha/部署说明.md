# 方案 B：GitHub Actions 全自动盯盘（30 分钟一次）

> 目标：电脑关机也能跑；命中条件自动推微信。
> 需要：GitHub 账号、Server酱 SendKey（微信扫码免费领）。全程约 20 分钟。

---

## 第 1 步：拿 Server酱 Key（5 分钟）

1. 打开 https://sct.ftqq.com/
2. 微信扫码登录
3. 点「SendKey」→ 复制那串 `SCT...` 开头的 Key
4. 点「消息通道」，按提示扫码绑定微信（不绑定收不到）

---

## 第 2 步：建仓库（3 分钟）

1. 登录 GitHub → 右上角 `+` → **New repository**
2. 名称随意，例如 `gold-radar`
3. 选 **Private**（推荐）或 Public 都可以
4. 勾选 **Add a README file** → Create

---

## 第 3 步：上传文件（5 分钟）

把本目录（`gold-monitor`）里的这些文件上传到**仓库根目录**：

```
fetch_full.py
analyze.py
radar.py
backtest.py
upgrade_backtest.py
build_page.py
update.py
notify.py          ← 从 gha/ 目录拿
```

以及把 `gha/workflow.yml` 放到：

```
.github/workflows/monitor.yml
```

> 网页上传：仓库页 → Add file → Upload files → 拖进去 → Commit。
> 注意 `.github/workflows/` 目录要先建：Add file → Create new file，文件名输入 `.github/workflows/monitor.yml`，再把 yml 内容粘进去。

---

## 第 4 步：加 Secret（2 分钟）

仓库 → **Settings** → 左侧 **Secrets and variables** → **Actions** → **New repository secret**

- Name：`SERVERCHAN_KEY`
- Secret：粘贴第 1 步的 Key
- Add secret

---

## 第 5 步：开 Pages（2 分钟）

仓库 → **Settings** → 左侧 **Pages**

- Source 选 **GitHub Actions**（不要选 Deploy from a branch）

---

## 第 6 步：跑第一次（2 分钟）

1. 仓库 → **Actions** 标签 → 左侧 `gold-monitor` → 右侧 **Run workflow** → Run
2. 等 1~3 分钟，绿勾出现
3. 回到 **Settings → Pages**，顶部会显示网址：`https://你的用户名.github.io/gold-radar/`
4. 手机/电脑打开这个网址，就是最新页面；命中条件时微信会收到推送

---

## 定时表

| 北京时间 | 作用 |
|---|---|
| **15:15** | 内盘/亚盘收盘后确认（跑完整链，日线信号定调） |
| **05:15** | 伦敦金/美盘收盘后确认（跑完整链） |
| 其余每 30 分钟 | 常规刷新，供 1H/4H 短线提示 |

> GitHub 的 cron 不保证准点，通常延迟 5~15 分钟；15:15 的任务实际可能在 15:20~15:30 跑完，属正常。
> 私有仓库每月 2000 分钟免费额度：48 次/天 × 约 1 分钟 ≈ 1500 分钟/月，够用但别再加频次；公开仓库不限。

## 常见问题

| 问题 | 说明 |
|---|---|
| 为什么不是秒级？ | GitHub 免费 cron 最小 5 分钟，且常有 5~15 分钟延迟；30 分钟是稳定值 |
| 电脑要开机吗？ | 不用，全在 GitHub 云端跑 |
| 会花钱吗？ | 公开仓库免费；私有仓库每月 2000 分钟免费额度，这个任务一次约 1 分钟，30 分钟一次 ≈ 1440 分钟/月，够用 |
| 想改成 15 分钟？ | 把 `cron: "*/30 * * * *"` 改成 `"*/15 * * * *"`，但私有仓库额度会吃紧 |
| 微信没收到？ | 检查 Server酱 是否绑定微信、SendKey 是否填对、Actions 日志里 `[notify]` 返回值 |
| Pages 打不开？ | Settings → Pages 里 Source 必须是 **GitHub Actions**，且第一次 deploy 成功后才出网址 |

## 安全提醒

- Server酱 Key 只放在 **Secrets** 里，不要写进代码或 README；
- 仓库建议 Private；
- 这个系统只做数据提示，不下单、不碰账户。
