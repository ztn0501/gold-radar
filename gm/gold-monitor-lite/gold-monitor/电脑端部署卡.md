## 4. 建自动运行脚本

回到仓库首页 → **Add file** → **Create new file**

**文件名那一栏，完整输入这一串**（打 `/` 会自动变成文件夹层级）：

```
.github/workflows/monitor.yml
```

然后把下面整段**全部粘进大文本框**（注意保留缩进，用空格不用 Tab）：

```yaml
name: gold-monitor

on:
  schedule:
    - cron: "15 7 * * *"
    - cron: "15 21 * * *"
    - cron: "*/30 * * * *"
  workflow_dispatch:

permissions:
  contents: write
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: true

jobs:
  build:
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deploy.outputs.page_url }}
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-python@v5
        with:
          python-version: "3.11"

      - name: run
        env:
          SERVERCHAN_KEY: ${{ secrets.SERVERCHAN_KEY }}
        run: |
          rm -rf /tmp/gm && mkdir -p /tmp/gm /workspace/gold-monitor
          unzip -o gold-monitor-lite.zip -d /tmp/gm
          cp /tmp/gm/gold-monitor/*.py /workspace/gold-monitor/
          cp /tmp/gm/gold-monitor/gha/notify.py ./notify.py
          python3 /workspace/gold-monitor/update.py
          cp /workspace/gold-monitor/index.html ./index.html
          python3 notify.py

      - name: commit
        run: |
          git config user.name "gold-bot"
          git config user.email "gold-bot@users.noreply.github.com"
          git add index.html alert_state.json
          git diff --staged --quiet || git commit -m "update $(date -u +%F_%H%M)"
          git push

      - uses: actions/upload-pages-artifact@v3
        with:
          path: .

      - id: deploy
        uses: actions/deploy-pages@v4
```

拉到底 → **Commit changes**。

## 9. 出错了怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| Actions 里根本看不到 `gold-monitor` | 第 4 步文件名没输全，缺 `.github/workflows/` | 删掉重建成正确路径 |
| 报 `Invalid workflow file` | yaml 缩进错（用了 Tab 或空格数不对） | 全选删除，重新粘贴一次，别手动改缩进 |
| 日志里 `403 Forbidden` | 新浪行情接口限流 | 点 **Re-run jobs** 再跑一次，通常第二次就过 |
| Pages 页面 404 | 第 6 步 Source 没选 GitHub Actions | 回去改成 GitHub Actions，再跑一次第 7 步 |
| 微信没收到推送 | 没绑微信 或 Key 填错 | sct.ftqq.com 里绑定微信；Secret 名必须是 `SERVERCHAN_KEY` |
